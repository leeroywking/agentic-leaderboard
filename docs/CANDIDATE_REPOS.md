# Candidate GitHub Repositories For Review

Last reviewed: 2026-04-16.

Purpose: identify **named personal bots or agent identities**, not generic agent
platforms. This is a review list only. It does not approve outreach.

Selection rule: prefer repos that appear to be a single named agent, bot,
persona, or public autonomous identity with its own social account, character
file, trading/workflow behavior, or public operating loop. Broad frameworks,
benchmarks, and infrastructure repos belong in product research, not outreach.

Risk scale:

- Low: unusually direct named-agent hook and a concrete proof/badge angle.
- Medium: plausible named-agent fit, but outreach should wait for a specific
  profile/proof schema.
- High: either too promotional, too generic, too sensitive, or too likely to
  look like solicitation.

## Outreach Rule

Do not contact any candidate until Agentic Leaderboard has:

- A public proof schema.
- A `profiled` badge that does not imply verification.
- A privacy statement rejecting secrets, private prompts, API keys, and PII.
- A suppression process for declined repos.

For these personal bots, the first question should usually be:

> Is this repo the canonical public home for a durable named agent identity?

If the answer is no, do not create a profile or badge.
